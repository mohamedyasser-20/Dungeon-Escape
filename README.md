# 🐉 Dungeon Escape Quest

A console-based dungeon adventure game built with **C++**.

## 🎮 Features

* 🗺️ 10×10 dungeon map
* ⚔️ Multiple enemy types and boss battles
* 🛡️ Health and armour systems
* 🎁 Chests containing weapons, armour, and potions
* 🪤 Random traps and dangerous encounters
* 🧙 Character classes and special abilities
* 🏰 Multiple floors to explore
* 🐲 Final battle against the Ancient Dragon

## 🛠️ Technologies

* C++
* Standard C++ libraries
* Console-based interface with colored text

## ▶️ How to Run

1. Clone or download this repository.

2. Compile the source file using a C++ compiler:

   ```bash
   g++ main.cpp -o DungeonEscape
   ```

3. Run the game:

   **Windows:**

   ```bash
   DungeonEscape.exe
   ```

   **Linux/macOS:**

   ```bash
   ./DungeonEscape
   ```

## 🎯 Objective

Explore the dungeon, collect equipment, survive dangerous encounters, defeat the Ancient Dragon, and reach the exit!
